# Asset provenance — Greyport Daylight

All runtime resources are local after setup. The public Git repository excludes `runtime/ferrari.glb` and the local gameplay screenshot; `npm run assets:prepare` retrieves the vehicle directly from its upstream distribution and verifies its recorded hash. Per-file source URLs, transformation notes, byte sizes and SHA-256 hashes are recorded in `source-manifest.json`.

## Ferrari 458 vehicle

- Creator credited by the upstream example: **vicent091036**.
- Downloaded from: https://threejs.org/examples/models/gltf/ferrari.glb
- Upstream example and attribution: https://threejs.org/examples/webgl_materials_car.html
- Original author link provided upstream: https://sketchfab.com/models/57bf6cc56931426e87494f554df1dab6
- Upstream source history: https://github.com/mrdoob/three.js/commit/6eec560494b0492cb72b6120ea2405bf4e4fe9c7
- The example labels the resource “Ferrari 458 Italia”; its dashboard geometry carries a “458 Spider” label. The resource is retained as supplied.
- Modifications: application-side materials; wheel pivots; steering animation; separated mirror surface; driver hands and live instrument face; stowed sun visors, a dark windshield surround, and fitted driver camera positions. The downloaded GLB itself is unchanged.
- The three.js software distribution is MIT licensed (see `LICENSE-three.txt`). The original Sketchfab model page/API did not return a usable model-license record during this implementation. **No CC0 or CC-BY license is asserted for the car.** Original-model permission must be resolved before independently redistributing the vehicle asset or publishing a release containing it. This checkout is a local development build.
- Ferrari names and marks identify the model; this project is not affiliated with Ferrari.

Asset license: https://polyhaven.com/license

- Asphalt 02: https://polyhaven.com/a/asphalt_02

- Brick Wall 001: https://polyhaven.com/a/brick_wall_001

- Kloppenheim 06 Pure Sky: https://polyhaven.com/a/kloppenheim_06_puresky

1K color, OpenGL normal and roughness maps were converted to WebP. Leaf color and alpha were combined and cropped to a branch atlas; bark was resized to 512 px. The tree geometry is generated by this project; the 95 MB source tree mesh is not included. The HDR is the original 1K file.
