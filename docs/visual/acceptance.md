# Greyport 0.5.0 — 电脑端验收

实施与验证：2026-11-18 至 2026-11-19（Asia/Shanghai）。设备：Apple M1、8 GB 内存，Codex 内置 Chromium 浏览器。

## 已落地

- 精细 458 车型、原生内饰、独立转向/滚动轮组、车身俯仰与侧倾、逐轮路缘支撑。
- 保留约 764 米完整环线；46 栋临街建筑，商业街 18 栋、砖混街区 18 栋、仓储段 10 栋，另有远景楼群。
- 1K 扫描沥青、砖、混凝土与铺装纹理，立体窗框/窗台/店面、遮雨棚、街灯、排水口、井盖与街道设施。
- 扫描树叶材质、分枝树冠、轻微风动与远近细节切换。
- 固定下午太阳、天空散射和云、HDR 环境光、跟随驾驶区域的阴影、三个街区反射探针。
- 统一世界坐标下的车内外照明、真实后方场景的车内后视镜、实时圆形仪表和握持动画。
- 五镜头、眼位设置、三档画质、加载进度、故障提示与重试、资源本地化。
- 发动机谐波、胎噪、风噪和座舱滤波等本地合成声层。

运行资产共 16 个，5,976,550 字节（约 6 MB）。当前使用 WebP 与 Draco；没有为了形式上的格式一致而引入额外 KTX2 转码依赖。

## 自动化验证

- `npm test`：54 项通过，0 失败（含后续手机连接状态修复）。
- 新增实际 GLB 完整性与轮组/内饰节点检查、本地资源服务 MIME 与路径边界、加载重试/取消、建筑间距与道路净空、逐轮支撑、刚性镜头跟随、未加载窗口拒绝远程开始。
- 用本地 Draco 解码实际交付车模，检查 648×864、1920×1080 下，0–18 cm 每 1 cm 眼位的中央道路射线。收起遮阳板，高位镜头适当前移避开完整顶框，全部通过。
- `npm run test:lap`：三圈全部有效、零碰撞；总时间 100.033 s。它是离线确定性回归，不是用户或手机成绩。
- `npm run build`：通过；应用、Three 核心与扩展分块，构建无块大小提示。

新增手机配对修复：选择手机模式与实际输入就绪分离；服务离线、扫码、校准、启动控制和数据超时分别提示，禁用状态不再显示等待光标。

## 浏览器检查

- 展示、驾驶、座舱和五种镜头的实际渲染。
- 实际键盘加速至约 96 km/h、制动、暂停/恢复；仪表读数跟随车辆状态。
- 完整环线的独立画面巡检与三档画质加载。
- 窄窗口 648×864 和宽屏 1920×1080；眼位调节及画质设置保存。
- 使用仅作用于检查标签页的网络阻断，让 GLB 加载失败：出现错误与重试按钮，开始比赛保持禁用。解除阻断、恢复缓存设置并重试后正常加载。
- 冷启动先准备座舱、后视镜和外观着色程序，避免第一次切进座舱时的编译停顿触发比赛暂停。

## 性能记录

以下是实现过程中的现场采样，统计最近 600 个渲染帧；帧率为采样均值。它们不是所有街段的最低帧率，也不能代替每台电脑的性能结果。

| 配置与场景 | 实际渲染尺寸 | 采样 FPS | P95 帧时间 |
|---|---:|---:|---:|
| 均衡，追逐巡检 | 1920×1080 | 约 60 | 约 19.4 ms |
| 流畅，追逐巡检 | 1460×821 | 约 60 | 约 18.4 ms |
| 精细，追逐巡检 | 1920×1080 | 约 37–39 | 约 28–29 ms |
| 精细，座舱（含后视镜） | 1920×1080 | 约 32 | 约 33.4 ms |
| 合并手部、优化天空遮挡后，均衡座舱 | 1603×911 | 约 60 | 约 18.9 ms |

默认推荐均衡。精细档增加 4096 阴影和环境遮蔽，在这台 M1 上有明显成本。流畅档限制像素预算并停用动态车内镜。优化包括：按材质合并建筑几何、树叶实例化与 LOD、有限反射探针、固定低频后视镜、按像素预算限制渲染尺寸，以及利用已有深度跳过被实体遮住的天空像素。

## 与最初方案的取舍及剩余边界

- 完成的是浏览器实时写实升级：建筑仍为模块化生成，手套/手臂仍为简化模型。没有声称达到真实街区摄影测量或照片级复刻。
- 静态街区反射探针替代持续更新的六面车身反射；后视镜使用 320×96、最多 5 Hz 更新。
- 道路中心线与核心计圈/输入逻辑继续采用现有实现。路缘高度用于视觉轮胎支撑，未宣称实现完整悬架动力学。
- 音效采用本地合成，没有声称使用实车录音。
- 用户明确选择“先完成电脑端，手机稍后测”。iPhone 物理握持、真机三圈与实际断连重连验收留待用户实测；自动协议、真实 UDP/WebSocket 测试已通过。
- 车辆来自有作者署名的 Three.js 示例。其原始 Sketchfab 许可记录尚未取回；当前是本地开发版，公开再分发车辆前需补齐模型许可或替换模型。扫描材质/HDR 为 CC0。详见 `assets/ATTRIBUTIONS.md`。
