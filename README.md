# Greyport / Steering Racer

使用 iPhone 作为体感方向盘的本地 3D 赛车原型。项目路径为 `/Users/bytedance/Documents/games/steering-racer`，独立于第一阶段 Steering Lab。

当前版本已升级为 Greyport 城市竞速版（原生 App 为 Build 5），详见 `URBAN-EDITION.md`。第三个里程碑功能保留：手机可开始、暂停、继续、重置、查看成绩和再来一局，记住电脑并自动重连。完整使用流程见 `MILESTONE-3.md`。

## 启动

本机已经安装依赖，双击 `Start Coastline.command`，或在项目目录运行：

```bash
npm start
```

启动会先打包游戏资源，然后运行接收服务。浏览器打开：

- 游戏：<http://127.0.0.1:8850/game/>
- 体感诊断：<http://127.0.0.1:8850/controller>

首次在其他电脑使用时，需要 Node.js 22.12+ 或 24+，先执行 `npm ci`。停止服务可在运行终端按 Ctrl+C。全部资源和音效在本地生成，不依赖 CDN、云服务或外部素材下载。

默认游戏 HTTP 端口为 8850，UDP 为 41235，与第一阶段 8848 / 41234 并存。端口被占用时可以指定：

```bash
STEERING_HTTP_PORT=8851 STEERING_UDP_PORT=41236 npm start
```

## 手机驾驶

第三阶段需要安装本项目的 App Build 3。旧 Build 2 仍可用第二阶段体感功能，但不支持新的比赛按钮和连接记忆。

1. 手机和 Mac 连接同一 Wi-Fi。
2. 电脑游戏页面选择“iPhone 体感”或右上角“连接手机”。
3. 在已安装的 Steering Lab App 中扫码；必须扫本项目二维码，原控制台的二维码对应另一个服务。
4. 用舒适姿势横握手机，点“校准中位”，保持约一秒不动，再点手机“开始比赛”。
5. 电脑自动切换手机模式并进入三秒倒计时。随后按住手机油门起步；左右旋转手机转向，按住刹车制动。比赛中的暂停、继续、重置、结算后的再来一局都在手机操作。

油门与刹车同时按下时刹车优先。手机 App 的原始映射为 ±35° 满舵、中心 ±2° 死区；游戏默认增加 1.65 倍灵敏度，约 ±22° 即满舵。右上角“手感”可调 0.75～2.50 倍，自动保存在本机浏览器。高速时前轮最大转角降低，并限制横向加速度。松开油门会自然减速，没有自动油门或自动驾驶替代用户。

游戏已根据真机反馈在输入转换处修正手机与世界坐标的转向符号，手机 App 的“反转方向”建议保持关闭。

手机暂停、切后台、锁屏、传感器停止或网络中断会暂停比赛并冻结车辆和计时。恢复连接后需要在手机重新校准并点“继续比赛”，不会自动恢复油门。切换页面也会暂停比赛。

遇到连接问题可打开诊断控制台：检查本地网络权限、Mac 防火墙是否允许 Node UDP 端口、路由器是否启用客户端隔离，并选择实际 Wi-Fi 地址而不是 VPN 地址。只有真实已配对的 iPhone 输入能启用手机驾驶；诊断模拟器不会冒充手机。

## 键盘与游戏规则

| 操作 | 按键 |
|---|---|
| 加速 | W / ↑ |
| 刹车 | S / ↓ / 空格 |
| 左右转向 | A、D / ←、→ |
| 重置车辆到赛道 | R |
| 暂停 / 继续 | Esc |
| 切换追逐 / 座舱 / 引擎盖 / 保险杠 / 高位镜头 | C |
| 音效开关 | M |

键盘模式失去窗口焦点时暂停，避免按键释放事件丢失导致持续油门。手机模式允许电脑窗口失焦，但页面进入后台仍然暂停。

赛道全长约 764 米，三圈一场，八个依次经过的检查点。仅正确方向完整经过检查点才计圈。倒退和起点反复穿越不能刷圈。R 将车辆放回最近赛道中心、清零速度，本圈可以完成，但不计个人最佳成绩。单圈和总时间仅在比赛运行时增长。

最佳有效单圈保存在本机浏览器 localStorage 中；不同浏览器的记录独立。浏览器存储不可用时仍可游戏，本次会话保留成绩。护栏会限制车辆位置并降低速度，驶出路面会减速和降低抓地力。

本阶段没有倒车挡、对手、漂移系统、车辆损伤或复杂悬挂；卡住时使用 R 重置。

## 开发结构

```text
shared/track.js       周期样条赛道、弧长采样、最近点投影
shared/physics.js     60 Hz 车辆运动、碰撞、计圈、比赛状态机
shared/input.js       键盘输入与手机新鲜度判断
src/game/world.js    Three.js 场景、车辆、赛道和镜头
src/game/main.js     交互、HUD、暂停、计时、手机配对
src/game/audio.js    本地 Web Audio 引擎音
server/              复用第一阶段 UDP 协议、认证与本机 WebSocket
public/control/      体感诊断页面
public/game/         Vite 生成的游戏资源（可重新构建）
ios/                 Build 3 App：比赛控制、成绩回传、记忆和重连
tests/               物理、计圈、超时与真实 UDP/WebSocket 测试
```

修改游戏源码后执行 `npm run build`，刷新网页即可。修改服务端后需要重启 Node 服务并重新扫码配对。iOS 工程复制自第一阶段，签名仍使用同一 Bundle Identifier，不会额外占用免费开发 App 名额。

## 验证

```bash
npm test
npm run test:lap
npm run test:swift
npm run build
```

`test:lap` 使用确定性的参考驾驶程序检验同一套物理和计圈逻辑，输出三圈成绩；它是离线回归测试，不代表用户成绩，也不向游戏注入虚假手机输入。实际验证记录见 `VALIDATION.md`。

渲染需要 WebGL 2。默认像素比最多 1.75，物理以固定 60 Hz 更新，渲染跟随显示刷新率。网络 RTT 仅表示通信往返时间，不代表完整操作到画面的延迟。

第三阶段完整协议、错误码和重连边界见 `MILESTONE-3.md`，最新验收记录见 `VALIDATION-M3.md`。持久配对文件位于 `.local/`，请勿打包或提交其密钥。
